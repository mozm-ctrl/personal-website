## 这是什么

加一行代码，网站右下角就会出现「AI 聊天 + 联网搜索」按钮。可选：只让登录用户使用，并从用户自己的积分里扣费。

详细参数见同目录的 `README.md`。

---

## 一、在自己电脑上试用

打开终端，整段粘贴，按回车：

```bash
kill $(lsof -t -iTCP:3001 -sTCP:LISTEN) 2>/dev/null
cd ~/Documents/Codex/search-chat/widget
export LLM_BASE_URL=http://localhost:11434/v1 LLM_MODEL=qwen3:8b LLM_REASONING_EFFORT=none
export PRICE_PER_REQUEST=0 PRICE_PER_SEARCH_DUCKDUCKGO=0 PRICE_PER_SEARCH_TAVILY=1 PRICE_PER_SEARCH_BOCHA=1
go run ./examples/billing-demo
```

浏览器打开 http://localhost:3001 ，点「以 alice 登录」，再点右下角按钮提问。终端窗口别关，用完按 `Ctrl + C`。

## 二、加到别人的网站

网站访客什么都不用装。下面只需对方技术人员做一次。

**准备：** 这个 `widget` 文件夹、一个模型 Key（DeepSeek / OpenAI 等）、一台服务器。

### 只要聊天，不扣积分（任何网站）

1. 把 `.env.example` 复制成 `.env`，填上模型 Key、模型名、网站地址。
2. 在服务器上运行：
   ```bash
   docker build -t search-chat . && docker run -d -p 8080:8080 --env-file .env --restart unless-stopped search-chat
   ```
3. 在网站页面里加一行：
   ```html
   <script src="https://聊天服务地址/chat-widget.js"></script>
   ```

### 要按用户扣积分（Go 网站）

1. 把 `searchchat/` 文件夹复制进项目。
2. 照着 `examples/billing-demo/main.go` 写 4 个函数，接上自己的用户表和余额表：登录校验 `Authenticate`、冻结 `Reserve`、结算 `Settle`、退款 `Refund`。README 里有可照抄的 SQL 写法。
3. 在页面里加一行，并把用户的登录 Token 交给它：
   ```html
   <script src="/ai/chat-widget.js" data-auth-storage="存Token的键名"></script>
   ```

## 三、计费怎么配

| 想要 | 填这些环境变量 |
| --- | --- |
| 每次提问扣 1 积分 | 不用填（默认） |
| DuckDuckGo 免费，用收费搜索才扣 1 | `PRICE_PER_REQUEST=0` `PRICE_PER_SEARCH_DUCKDUCKGO=0` `PRICE_PER_SEARCH_TAVILY=1` `PRICE_PER_SEARCH_BOCHA=1` |
| 每次扣 2，搜索再加 1 | `PRICE_PER_REQUEST=2` `PRICE_PER_SEARCH=1` |

出错、超时、用户中途离开都会全额退回。

## 常见问题

- **报「缺少 LLM_BASE_URL」**：`export` 和 `go run` 要在同一个终端窗口里执行。
- **报 `address already in use`**：旧的还在跑，先在原窗口按 `Ctrl + C`。
- **聊天框「连不上聊天服务」**：网站地址没写进 `.env` 的 `ALLOWED_ORIGINS`，或网站是 https 而聊天服务是 http。
