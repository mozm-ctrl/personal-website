# 搜索引擎接口使用说明：DuckDuckGo 与 SearXNG

版本：v1.1　日期：2026-11-04　编写：莫祖铭

## 0. 概览

| | DuckDuckGo（ddgs） | SearXNG |
|---|---|---|
| 类型 | 搜索引擎（通过第三方 Python 库调用） | 开源元搜索引擎（聚合 Google、Bing、DuckDuckGo 等） |
| 调用方式 | Python 函数 `DDGS().text()` | HTTP 接口 `GET /search?format=json` |
| 部署 | 无需部署，`pip install` 即用 | 需自行部署（推荐 Docker） |
| 费用 | 免费，无需注册和 Key | 免费，自部署无调用次数限制 |
| 稳定性 | 高频请求会被临时限流 | 单个上游失败时仍可从其他引擎返回结果；部分上游会被限流或要求验证码，见 2.5 |
| 适用场景 | 快速验证、Demo | 长期、稳定使用 |

---

## 1. DuckDuckGo

### 1.1 说明

- DuckDuckGo **没有官方的网页搜索 API**。本文使用社区维护的 Python 库 `ddgs`（原名 `duckduckgo_search`），通过模拟网页请求获取结果。
- 官方的 `api.duckduckgo.com` 是"即时答案"接口，只返回百科摘要，**不返回网页搜索结果**，不适合联网搜索场景。
- 测试环境：`ddgs` 9.8.0，Python 3.9，macOS。

### 1.2 安装

```bash
pip install ddgs
```

### 1.3 网页搜索 `text()`

```python
from ddgs import DDGS

results = DDGS(timeout=10).text(
    "大模型 联网搜索",
    region="cn-zh",
    safesearch="moderate",
    timelimit="w",
    max_results=5,
)
for r in results:
    print(r["title"], r["href"])
    print(r["body"])
```

**请求参数**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| `query` | str | 是 | — | 搜索词 |
| `region` | str | 否 | `us-en` | 地区/语言，如 `cn-zh`、`us-en`、`wt-wt`（不限） |
| `safesearch` | str | 否 | `moderate` | `on` / `moderate` / `off` |
| `timelimit` | str | 否 | `None` | 时间范围：`d` 天 / `w` 周 / `m` 月 / `y` 年 |
| `max_results` | int | 否 | `10` | 返回条数上限 |
| `page` | int | 否 | `1` | 页码 |
| `backend` | str | 否 | `auto` | 搜索后端，见 1.6 |

构造参数：`DDGS(timeout=10)` 设置单次请求超时（秒），`DDGS(proxy="http://...")` 设置代理。

**返回值**：`list[dict]`

| 字段 | 说明 |
|---|---|
| `title` | 网页标题 |
| `href` | 网页链接 |
| `body` | 摘要片段 |

### 1.4 新闻搜索 `news()`

```python
news = DDGS(timeout=10).news("人工智能", region="cn-zh", timelimit="d", max_results=5)
```

返回字段：`title`、`url`、`body`、`date`、`source`、`image`。

同类方法还有 `images()`（图片）、`videos()`（视频），参数基本一致。

### 1.5 异常处理

```python
from ddgs import DDGS
from ddgs.exceptions import DDGSException, RatelimitException, TimeoutException

try:
    results = DDGS(timeout=10).text("测试", max_results=5)
except RatelimitException:
    print("被限流，稍后重试")
except TimeoutException:
    print("请求超时")
except DDGSException as e:
    print("搜索失败：", e)   # 包括 "No results found."
```

### 1.6 注意事项

- `ddgs` 9.x 本身也是一个"元搜索"库：`backend="auto"` 时会在 DuckDuckGo、Bing、Brave 等多个后端之间选择。实测中指定 `backend="duckduckgo"` 搜中文出现过 `No results found`，**建议保持默认 `auto`**。
- macOS 自带的 Python 3.9 偶尔会报 `ValueError: Unsupported protocol version 0x304`（ddgs 随机选到了 TLS 1.3 配置），**重试一次即可**。
- 请求间隔建议 1～2 秒，不要并发高频调用；被限流时等待 1～2 分钟。
- `body` 只是摘要，如需正文需另行抓取网页。

## 2. SearXNG

### 2.1 说明

- SearXNG 是开源的**元搜索引擎**，本身不爬取网页、没有索引，而是把查询转发给多家搜索引擎并汇总、去重、排序。
- 公共实例大多关闭了 JSON 接口，**需要自行部署**。
- 测试环境：Docker 镜像 `searxng/searxng:latest`（版本 `2026.11.2-cccbc9e15`），Apple M4 macOS，Docker Desktop，国内网络、未使用代理。

### 2.2 部署（Docker）

```bash
# 1. 首次启动，生成配置文件
mkdir -p ~/searxng
docker run -d --name searxng --restart unless-stopped \
  -p 8888:8080 -v ~/searxng:/etc/searxng searxng/searxng

# 2. 编辑 ~/searxng/settings.yml，开启 JSON 格式（见下）

# 3. 重启生效
docker restart searxng

# 4. 验证（返回 200 和 JSON 即成功）
curl "http://localhost:8888/search?q=test&format=json"
```

首次启动时，容器会在挂载目录里自动生成一个最小的 `settings.yml`（`use_default_settings: true`），并**自动写入随机的 `secret_key`**，不需要手动设置。在此基础上补上以下内容即可：

```yaml
use_default_settings: true

server:
  secret_key: "（自动生成，保留即可）"
  image_proxy: true
  limiter: false  # 仅本机使用时关闭自带限流，避免 429

search:
  formats:
    - html
    - json        # 不加会返回 403
```

常用命令：`docker stop searxng` / `docker start searxng` / `docker restart searxng` / `docker logs searxng`。

### 2.3 接口定义

**请求**：`GET http://localhost:8888/search`（POST 表单同样可用，已实测）

| 参数 | 必填 | 说明 | 示例 |
|---|---|---|---|
| `q` | 是 | 搜索词；缺少时返回 400 | `大模型 联网搜索` |
| `format` | 是 | 返回格式 | `json` |
| `language` | 否 | 语言；不认识的值会被忽略，不报错 | `zh-CN`、`en`、`all` |
| `categories` | 否 | 分类，逗号分隔 | `general`、`news`、`science`、`images` |
| `engines` | 否 | 指定上游引擎，逗号分隔；可调用默认未启用的引擎（如 `bing`） | `bing,duckduckgo,wikipedia` |
| `pageno` | 否 | 页码，从 1 开始；`0` 返回 400 | `1` |
| `time_range` | 否 | 时间范围；只支持这 4 个值，其他值返回 400 | `day`、`week`、`month`、`year` |
| `safesearch` | 否 | 安全搜索；超出范围返回 400 | `0` 关 / `1` 中 / `2` 严 |

参数值不合法时返回 HTTP 400，正文为 `{"error": "Invalid value hour for parameter time_range"}` 这样的 JSON。

**响应示例**（实测摘录，`q=大模型 联网搜索`）

```json
{
  "query": "大模型 联网搜索",
  "results": [
    {
      "title": "大模型如何联网搜索-大模型服务平台百炼(Model Studio) - 阿里云文档",
      "url": "https://help.aliyun.com/zh/model-studio/web-search",
      "content": "8 days ago ... 使用方式 · 通过 tools 参数添加 web_search 工具即可启用联网搜索。...",
      "engine": "google cse",
      "engines": ["brave", "google cse"],
      "score": 4.0,
      "category": "general",
      "publishedDate": null
    }
  ],
  "answers": [],
  "corrections": [],
  "infoboxes": [],
  "suggestions": ["ddg搜索接口", "ollama 联网", "langchain搜索引擎"],
  "unresponsive_engines": [["duckduckgo", "CAPTCHA"], ["wikidata", "timeout"]]
}
```

| 字段 | 说明 |
|---|---|
| `results` | 结果列表（核心） |
| `results[].title` / `url` / `content` | 标题 / 链接 / 摘要 |
| `results[].engine` | 排在首位的来源引擎 |
| `results[].engines` | 返回该条结果的所有上游引擎，命中引擎越多 `score` 越高 |
| `results[].score` | 综合排序分，结果已按它降序排列 |
| `results[].category` | 所属分类，如 `general`、`news` |
| `results[].publishedDate` | 发布时间（如 `2026-11-04T02:22:52`）；新闻类大多有值，网页类多为 `null` |
| `suggestions` | 相关搜索建议；中英文基础搜索有，指定 `language` 后常为空 |
| `corrections` | 拼写纠正建议 |
| `unresponsive_engines` | 本次失败或超时的上游引擎，格式为 `[引擎名, 原因]` |

注：
- 当前版本的响应里**没有 `number_of_results` 字段**，结果数以 `results` 的实际长度为准。
- 每条结果还带有 `thumbnail`、`img_src`、`positions`、`parsed_url`、`template` 等字段，供网页版渲染用，一般用不到。

### 2.4 Python 调用示例

```python
import requests

def searxng_search(query, max_results=5, base_url="http://localhost:8888"):
    resp = requests.get(
        base_url + "/search",
        params={"q": query, "format": "json", "language": "zh-CN"},
        timeout=15,
    )
    resp.raise_for_status()
    items = resp.json().get("results", [])[:max_results]
    # 字段统一成与 ddgs 一致的 title / href / body，便于两者互换
    return [{"title": r.get("title"), "href": r.get("url"), "body": r.get("content", "")}
            for r in items]
```

实测 `searxng_search("大模型 联网搜索")` 约 0.9 秒返回 5 条结果（阿里云、腾讯云、知乎、CSDN 等）。

### 2.5 上游引擎实测

默认启用的网页引擎为 `google cse`、`brave`、`duckduckgo`、`wikipedia`、`wikidata`（另有翻译、汇率等小工具）；新闻类为 `bing news`、`duckduckgo news`、`google news`、`reuters`、`wikinews`、`brave.news`。

| 引擎 | 默认启用 | 实测情况 |
|---|---|---|
| `google cse` | 是 | 稳定，每次约 20 条，是默认配置下的主要结果来源 |
| `brave` | 是 | 前几次可用，之后报 `too many requests` 并被暂停 |
| `duckduckgo` | 是 | 时好时坏，经常报 `CAPTCHA` |
| `wikipedia` | 是 | 可用，只在有对应词条时返回 1 条 |
| `wikidata` | 是 | 经常 `timeout` |
| `bing` | 否 | 用 `engines=bing` 指定时稳定，约 10 条 |
| `yahoo` | 否 | 用 `engines=yahoo` 指定时可用，约 7 条 |
| `360search` | 否 | 可用，但较慢（3～5 秒），条数少 |
| `google` | 否 | `access denied` |
| `baidu` | 否 | `CAPTCHA` |
| `sogou` | 否 | `timeout` |
| `qwant` | 否 | `access denied` |
| `duckduckgo news` / `bing news` / `wikinews` | 是 | 可用，新闻搜索的主要来源 |
| `google news` / `brave.news` / `reuters` | 是 | 分别报 `access denied` / `too many requests` / `HTTP error` |

响应时间：连续 10 次默认网页搜索（间隔 2 秒），平均 0.94 秒（0.75～1.15 秒），10 次都有结果；但后期结果全部来自 `google cse`，`brave` 和 `duckduckgo` 每次都在 `unresponsive_engines` 里。带新闻分类或首次查询时约 2～3 秒。

> 以上结果与网络环境、IP 有关，换网络或使用代理后可能不同。

### 2.6 注意事项

- **引擎被暂停**：上游报错后，SearXNG 会暂停该引擎一段时间，原因前会带 `Suspended:`，例如 `["brave", "Suspended: too many requests"]`。暂停期间请求该引擎会立即返回空结果（约 0.01 秒）。
- **建议显式指定引擎**：默认配置下实际只靠 `google cse` 一家，没有发挥"聚合"的作用。实测 `engines=bing,duckduckgo,wikipedia` 一次返回 13 条、无失败。长期使用可在 `settings.yml` 中启用 `bing` 等可用引擎。
- **`engines` 写错不报错**：引擎名不存在（如 `engines=notanengine`）时不会报错，而是退回默认引擎。
- **`time_range` 不是对所有引擎生效**：不支持时间过滤的上游引擎会被跳过，所以加上 `time_range` 后结果可能变少。
- **`safesearch` 对网页结果影响很小**：`0` 和 `2` 搜 `python` 的结果一致。
- **`pageno=2`** 可正常翻页，但部分引擎第二页不返回结果，条数会减少。
- 启动日志中出现 `ahmia`、`torch` 加载失败和缺少 `limiter.toml` 的提示，属正常现象，不影响使用。

### 2.7 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 403 Forbidden | 未开启 JSON 格式（已实测复现） | `settings.yml` 中 `formats` 加 `json`，重启 |
| 400 Bad Request | 缺少 `q`，或参数值不合法 | 查看返回的 `error` 字段 |
| 429 Too Many Requests | 自带 limiter 拦截 | 设置 `limiter: false` |
| `results` 为空 | 上游引擎均失败 | 查看 `unresponsive_engines`，换 `engines` 或稍后重试 |
| 连接被拒绝 | 容器未运行 | `docker start searxng`；查看日志 `docker logs searxng` |

## 3. 选型建议

- **原型 / Demo**：DuckDuckGo（ddgs），零配置即可使用。
- **长期稳定使用**：自部署 SearXNG，无调用费用，不依赖单一上游；建议启用或显式指定 `bing` 等实测可用的引擎。
- **推荐组合**：以 SearXNG 为主、DuckDuckGo 为备用，两者返回字段已统一，可按需自动切换。
